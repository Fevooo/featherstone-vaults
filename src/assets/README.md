# One-off site photography

Files dropped here are picked up by name at build time through
`src/lib/site-images.ts`. Nothing breaks while the folder is empty.

| Filename | Where it appears | Format |
| --- | --- | --- |
| `cotswolds.jpg` | The "Rooted in history" panel on `/about` | landscape, 4:3, 1600px wide or larger |

Object and department photography does not go here. Those live beside their
markdown files in `src/content/objects/` and `src/content/collections/` and are
referenced from the front matter. See the root README.
